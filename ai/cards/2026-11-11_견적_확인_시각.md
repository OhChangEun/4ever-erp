# 견적 재고 확인 시각

- 출처: 금액과 숫자 언어별 형식 리뷰 P2
- 구현: Claude(메인 세션)

## 결과

1. 견적 검토의 "재고 확인 일시"가 렌더 때의 `new Date()` 라, 다른 탭에 갔다 오면(포커스 재조회) 확인 결과는 그대로인데 시각만 지금으로 바뀌었다.
2. 서버가 준 `inventoryCheckTime` 을 보이고, 없거나 날짜가 아니면 결과를 받은 시각(onSuccess 때 저장)을 보인다. 어느 쪽이든 다시 그려도 바뀌지 않는다.
3. 테스트 2개: 서버 시각을 쓴다(고치기 전 실패), 서버 시각이 잘못되면 Invalid Date 대신 받은 시각.

## 남긴 것

1. 게이트웨이는 재고 확인 응답을 Object 로 넘기고 DTO 에 `inventoryCheckTime` 이 없다. 실서버가 이 필드를 보내는지, 보낸다면 zone 이 붙는지는 확인 불가(verified=false). zone 없는 UTC 로 오면 9시간 어긋난다. 실서버 응답 하나로 확인한다.
