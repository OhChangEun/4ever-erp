# 디자인 토큰: packages/ui/tokens.css 한 곳, z-index 클래스 결함

- 출처: 계획 16-1 "디자인 시스템 토큰(packages/ui/tokens.css 하나로)". 작업 중 찾은 결함
- 우선순위: 1(겹치는 층이 잘못 보이면 화면이 상태를 숨긴다), 4
- 브랜치: feat/디자인_토큰
- 크기: 반나절

## 현상

1. 색, z-index, 애니메이션 토큰이 앱의 `src/styles/globals.css` 에 있다. Storybook 이 앱 파일을 빌려 와야 한다.
2. 결함: z-index 값(`--z-index-modal` 등)이 `:root` 변수로만 있고 Tailwind 유틸리티가 없다. `z-modal`, `z-popover`, `z-toast`, `z-overlay`, `z-header`, `z-sidebar`, `z-local` 클래스 7종이 32곳에 쓰였지만 CSS 가 만들어지지 않아 전부 `z-index: auto` 다(e2e 로 확인). 층 순서가 DOM 순서에만 기대고 있다. 예를 들어 토스트가 모달 오버레이 위에 온다는 보장이 없다.

## 완료 기준

1. 토큰 원본은 `packages/ui/tokens.css`(색 팔레트, z-index, 애니메이션). 앱과 Storybook 이 둘 다 이것을 가져온다.
2. z-index 클래스 7종이 `@utility` 로 토큰 값을 갖는다(e2e 가 실제 브라우저에서 계산값 확인).
3. 브랜드 색(blue-500 #2f4a7f)이 Tailwind 기본값을 덮는다(e2e).
4. Storybook 은 앱 `globals.css` 대신 토큰 파일을 쓴다. 색 토큰 스토리 하나.
5. 첫 로드 JS 그대로(CSS 만 바뀜). 테스트, 빌드, e2e 통과.

## 결정 (AI 가 정함)

1. 색은 `:root` 덮어쓰기 대신 `@theme` 에 둔다. Tailwind 가 기본 팔레트 대신 이 값으로 유틸리티를 만든다. 선언이 한 번이 된다.
2. z-index 는 Tailwind v4 에 테마 이름공간이 없어 `@utility z-modal { z-index: var(--z-index-modal) }` 꼴로 만든다.
3. 폰트(`next/font` 변수)는 앱 전용이라 앱에 남긴다.

## 결과

1. `packages/ui/tokens.css` 가 원본(색 50개 `@theme static`, z-index 8개와 `@utility` 7개, 애니메이션 5개). 앱 `globals.css` 는 201줄 → 81줄. Storybook 은 앱 파일 대신 토큰 파일을 가져온다.
2. z-index 결함: 클래스 7종 32곳이 `auto` 였던 것을 실제 값으로. e2e 가 브라우저 계산값을 확인한다.
3. 고친 뒤 드러난 결함: 모달 뒤 오버레이에 z-index 가 없어 `z-local`(10) 요소가 오버레이 위로 올라왔다. 오버레이에 `z-modal`.
4. 리뷰 P2: 쓰이지 않은 색 변수가 빠지는 문제를 `@theme static` 으로.
5. 색 토큰 스토리(팔레트 5개, 역할 설명).
6. 첫 로드 JS 그대로. 확인: lint 0 errors, tsc, 앱 310 + ui 47 + 플러그인 21, Storybook 빌드, e2e 61 통과 2 skip.
7. 남은 것: 간격, 반경, 글자 크기 토큰(지금은 Tailwind 기본값을 그대로 쓴다), DESIGN_GUIDELINES 12장의 표를 Storybook 문서로.
