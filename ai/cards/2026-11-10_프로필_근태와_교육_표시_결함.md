# 프로필 근태와 교육 표시 결함

## 근거와 수정

1. 출퇴근 버튼은 한국어 상태와만 비교했다. 팀 백엔드 `ProfileController`의 오늘 근태와 최근 근태는 `Object` 프록시라 상태 계약을 확정할 수 없다. 별도 HRM `AttendanceStatus`는 NORMAL/LATE지만 프로필 목은 ON_TIME을 준다. 프로필 계약과 목의 시간 필드를 기준으로 미출근, 출근, 퇴근 완료를 구분한다. 기존 한국어 퇴근완료도 허용하며 응답 전에는 버튼을 비활성화한다. 요청 형식은 유지했다.
2. 오늘과 최근 근태의 원시 상태를 `StatusLabel`로 표시한다. ON_TIME과 기존 한국어 상태의 ko/en 메시지를 추가했다. NORMAL/LATE는 기존 공통 메시지를 사용한다.
3. 교육 분류는 두 enum만 처리하고 나머지는 빈 문자열이었다. 백엔드 TrainingCategory의 BASIC_TRAINING/TECHNICAL_TRAINING과 목의 SAFETY/QUALITY/SYSTEM을 공통 라벨로 처리한다. HRM ProgramDetailModal이 사용하는 공통 BASIC_TRAINING의 "기본 교육"으로 프로필 메시지도 맞췄다.

## 검증

- `profile.defects.test.tsx` 15개 추가. 수정 전 9개가 버튼 상태, 근태 번역, 분류 누락과 명칭 차이로 실패했고 기존 호환 경로 6개는 통과했다. 수정 후 모두 통과했다.
- `pnpm exec tsc --noEmit -p .` 통과.
- `pnpm exec eslint .` 오류 0, 경고 0.
- `pnpm exec vitest run` 92개 파일, 569개 테스트 통과.
- `pnpm build` 통과. 빌드 후 루트와 포털 next-env.d.ts를 HEAD 내용으로 복원했다.

## 카드 밖에서 발견한 것

- ProfileHeader는 참조되지 않는다. 요청대로 보존했다.
- 휴가 신청은 성공 전에 모달을 닫고 입력을 초기화하므로 실패하면 입력이 사라진다.
- 오늘 근태와 최근 근태 조회 실패를 별도 오류 안내로 표시하지 않는다.
