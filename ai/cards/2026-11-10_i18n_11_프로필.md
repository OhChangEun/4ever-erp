# i18n 11: 프로필과 로그인 화면

- 출처: i18n 2 결과 6
- 브랜치: feat/i18n\_11\_프로필

## 결과

1. 한국어 문자열 265 → 129. profile 78 → 3, login 16 → 0, callback 7 → 0, unauthorized 7 → 0, `src/lib/auth` 47 → 16.
2. 프로필은 도메인 폴더 `src/i18n/messages/profile/` 에 넣고 이름공간은 `myProfile` 이다. 기본 메시지에 사이드바 프로필 메뉴용 `profile` 이 이미 있어 같은 이름이면 프로필 화면에서 사이드바 글자가 사라진다. 로그인, callback, unauthorized 는 작아서 기본 메시지의 `login`, `auth` 로.
3. 데모 로그인 카드: 메뉴는 `login.menu` 를 새로 뒀다(사이드바 `nav` 는 '영업관리'처럼 길어 카드 글자가 달라진다). 세션에 들어가는 이름(`displayName`)과 `department` 는 그대로.
4. 남긴 것: 세션 이름과 부서 16, 근태 상태 서버 값 3개('출근전', '퇴근완료', '정상', 비교용 상수), 서버가 보내는 로그인 오류 문구.
5. 동작이 바뀐 곳: 서버 오류 메시지가 빈 문자열이면 예전엔 아무것도 안 보였고 이제 "로그인에 실패했습니다."가 보인다.
6. 같이 고친 문구: callback 화면이 해요체와 합니다체를 섞어 써서 합니다체로("이동 중입니다", "준비하고 있습니다").
7. 남긴 결함(다음 카드 후보, Codex 구현 실험 대상):
   - 목 응답의 근태 상태가 `ON_TIME` 이라 '출근전' 비교가 늘 빗나가 프로필의 출퇴근 버튼이 항상 "퇴근하기".
   - 오늘과 최근 근태 상태 글자가 서버 값 그대로.
   - 교육 분류가 목에서 `SAFETY` 같은 코드라 " | 3시간"만 보인다. 공통 status 의 '기본 교육'과 이 화면의 '기초 교육'도 다르다.
   - `ProfileHeader` 는 어디서도 안 쓴다.
8. 첫 로드: /profile +2.0KB, /login +0.8KB, 나머지 +0.7~0.9KB(기본 메시지). 예산 안.
9. 확인: tsc, lint 0, vitest 532, build, 전체 e2e, 리뷰 지적 없음. 구현은 erp-dev 에이전트(worktree). 이 카드가 역할 교대 전 Claude 구현 마지막 카드다.
