# i18n 3: 창고 화면

- 출처: i18n 2 결과 6(도메인마다 같은 방식)
- 우선순위: 4, 3
- 브랜치: feat/i18n\_3\_창고

## 결과

1. 창고 화면 문구 126 → 0(키 98): 목록, 상세, 추가, 관리 모달, 3D 뷰(범례, 재고율 칸, 요약 카드, 장면 위 버튼). 3D 장면 블록의 품목 이름은 데이터라 그대로.
2. 계산 함수가 한국어를 돌려주지 않게: `BAND_LABEL` 삭제(화면이 단계 키로 번역), `buildCluster` 는 이름 없으면 `null`(화면이 "미지정 창고"), 통계 카드 값의 단위 '개'는 화면이 붙인다.
3. 창고 상태 "운영중"은 공통 `status.ACTIVE`("활성")와 글자가 달라 창고 메시지에 따로 둔다(한국어 그대로).
4. 한국어 문자열 2,015 → 1,889. 첫 로드: 창고 +2.1KB, 정적 렌더 유지.
5. 확인: verify, build, e2e 73 통과 2 skip, 영어 단위 테스트 3개, 리뷰 지적 없음. 구현은 erp-dev 에이전트, 번역 하나(재고율 caution: Low → Caution)와 검증은 메인 세션.
