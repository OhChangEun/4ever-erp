# 시각화 8: 창고 3D 를 실제 재고와 재고율 색으로

- 출처: 계획 17-1 "창고: 3D 랙을 재고율 heat 색으로, 클릭하면 재고 상세 모달. 동적 임포트", 17-2 규칙
- 우선순위: 1(3D 가 서버 재고를 그린다, 재고 mutation 뒤 같이 갱신), 2(부족 품목을 숨기지 않는다, 불러오기 실패를 보인다), 3(three.js 는 3D 를 열 때만)
- 브랜치: feat/시각화\_8\_창고\_3D\_heat
- 크기: 반나절

## 현상

창고 3D 뷰는 코드에 박힌 샘플 품목 8개(`SAMPLE_INVENTORY`)만 그린다. 어느 창고를 열어도 같은 그림이다. 허용 차트 규칙 5번(가짜 그래프 금지)에 걸린다. 색은 부족, 주의, 정상 세 가지인데 hex 상수라 토큰 밖이고, 3D 를 못 쓰는 사람은 품목을 고를 길이 없다.

## 완료 기준

1. 3D 는 그 창고의 실제 재고 목록을 그린다: 재고 목록 API(`type=WAREHOUSE_NAME`, `keyword=창고 이름`, 60개). 쿼리 키는 재고 도메인의 `inventoryKeys.list(params)` 라 재고 mutation 이 목록을 무효화하면 3D 도 다시 받는다. `SAMPLE_INVENTORY` 삭제.
2. 블록 색은 재고율(현재고 / 안전재고) 4단계: 부족(1 미만) red-500, 주의(1~~1.5) red-200, 적정(1.5~~3) blue-300, 많음(3 이상) blue-600. 안전재고가 0 이면 "기준 없음" gray-300. 색은 CSS 토큰에서 읽는다(three.js 재질은 CSS 변수를 못 받아 실행 때 값을 꺼낸다).
3. 옆 칸에 요약 문장(품목 수, 부족 수, 60개 넘으면 "N개 중 60개만 그렸습니다")과 재고율 낮은 순 품목 목록(버튼). 목록이나 블록을 누르면 같은 품목이 고른 상태가 된다. 키보드는 목록으로 같은 일을 한다.
4. 고른 품목 칸에 "재고 상세 열기" 버튼: 재고 화면과 같은 재고 상세 모달(30일 추이 포함)을 연다.
5. 로딩, 오류(TableStatusBox), 품목 없음.
6. 창고 첫 로드 JS 예산 안(3D 와 상세 모달은 3D 를 열 때만).

## 결정 (AI 가 정함)

1. 색은 갈라지는 두 색(빨강은 모자람, 파랑은 넉넉함). 노랑, 주황 토큰이 없어 새 색을 만들지 않는다.
2. 한 창고에 60개(랙 4개 × 칸 15)까지만 그린다. 넘으면 요약에 적는다. 블록 자리는 선반 번호 순서로 0번부터 채운다(서버 선반 번호가 겹치면 블록이 겹쳐 보였다).
3. 재고 상세는 새로 만들지 않고 재고 도메인 모달을 공개 입구(`ui.ts`)로 쓴다.

## 결과

1. `useWarehouseClusters` 가 재고 목록 API(`type=WAREHOUSE_NAME`, 60개)를 `inventoryKeys.list` 키로 받는다. 재고 도메인 공개 입구에 `getInventoryList`, `inventoryKeys`, `InventoryDetailModal` 을 열었다. `SAMPLE_INVENTORY`(샘플 8개)와 `stockColors.ts`(hex 상수), 안 쓰던 `warehouseVisualizerKeys` 를 지웠다.
2. `stockHeat.ts`: 재고율 4단계 + 기준 없음, 토큰 이름, 실행 때 CSS 토큰 값을 읽는 `readBandColors`. 범례도 같은 토큰 클래스.
3. 블록 자리는 선반 번호 순서로 매긴 `slot`(겹침 방지). 고른 품목 블록은 밝힌다.
4. 옆 칸 `WarehouseStockPanel`: 요약(부족, 주의 수, 60개 넘으면 일부만 그렸다고), 재고율 낮은 순 목록(버튼, `aria-pressed`), 고른 품목과 "재고 상세 열기".
5. 목: 창고 이름으로 거르면 품목 14개(부족 4, 주의 4, 적정, 많음, 기준 없음 1).
6. 첫 로드 JS: 창고 +1.3KB, 재고 +2.8KB(목 데이터와 공개 입구). 확인: lint 0 errors, tsc, 앱 398 + ui 53 + 플러그인 21, e2e charts 9 통과.
7. 남은 것: 창고 3D 모달이 공통 모달(Radix)이 아니라 Esc, 포커스 가두기가 없다(이 카드 범위 밖, 다음 카드 후보). 서버의 창고 이름 필터 동작은 verified=false.
