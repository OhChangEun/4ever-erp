# 재고 공개 입구에서 딸려 오는 모달 빼기

- 출처: CI 고도화 2 의 첫 PR 코멘트(번들 표): `/low-stock` 이 기준선 대비 +5.0KB(예산 끝)
- 우선순위: 3(첫 로드), 4(도메인 공개 입구 규칙)
- 브랜치: fix/재고\_공개\_입구\_가볍게
- 크기: 1시간

## 현상

안전재고 화면은 재고 도메인 `ui.ts` 에서 발주 요청 모달 하나를 정적으로 가져온다. 시각화 8 에서 `ui.ts` 에 재고 상세 모달을 더하자, 앱 코드는 `sideEffects` 표시가 없어 그 모달(30일 추이 포함)까지 안전재고 첫 로드에 딸려 왔다. 시각화 8 에서 `index.ts` 에 연 `getInventoryList` 도 키와 상수만 쓰는 화면(창고 목록)에 재고 api 를 끌어왔다.

## 완료 기준

1. 안전재고 화면의 발주 요청 모달을 `next/dynamic` 으로. 누를 때 받는다(e2e 로 열리는 것 확인).
2. `getInventoryList` 는 `index.ts` 에서 빼고 `ui.ts`(무거운 입구)로. 창고 3D 훅은 동적 청크 안이라 거기서 가져온다.
3. 의도한 증가(시각화 1~8)가 쌓인 기준선을 이 PR 에서 갱신한다.

## 결과

1. 첫 로드 JS(기준선 대비): 안전재고 -19.8KB, 창고 +0.7KB(전 +1.3), 재고 +2.7KB(재고 화면의 자기 모달, 그대로).
2. `perf/bundle-baseline.json` 갱신. 이후 PR 은 지금 숫자에서 +5KB 를 본다.
3. e2e: 안전재고에서 품목을 골라 발주 요청 모달이 열린다. 리뷰 지적 없음.
