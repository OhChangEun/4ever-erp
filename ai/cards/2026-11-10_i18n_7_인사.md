# i18n 7: 인사 화면

- 출처: i18n 2 결과 6
- 브랜치: feat/i18n\_7\_인사

## 결과

1. 인사 화면 문구 312 → 11. 직원, 부서, 직급, 근태와 근태 잔디, 휴가, 급여, 교육 탭과 모달, 토스트, 확인 문구, 통계 카드. 남은 11개는 교육 프로그램 추가 모달의 대상 부서 6개와 직급 5개로, 서버로 보내는 값이라 `programTargets.ts` 에 한국어 그대로 두고 화면 글자만 번역한다.
2. 인사 컴포넌트는 다른 화면에서 쓰지 않아 인사 레이아웃만 `HrmMessages` 로 감쌌다(프로필은 `hrm.keys` 만 가져다 쓴다).
3. 동작이 바뀐 곳: 인원, 일수, 시간이 1,000 이상이면 한국어도 쉼표가 붙는다(ICU 숫자 형식). 직급 상세 모달은 불러오는 동안 "명"만 보이던 것을 빈칸으로.
4. 같이 고친 것:
   - 부서 이름 뒤에 "팀"을 또 붙여 "영업팀팀"으로 보였다. 서버 값에 이미 "팀"이 있어 그대로 보인다(부서 목록과 부서 수정 모달의 비활성 칸).
   - "회원 등록 성공"과 "회원 등록에 실패" → "직원". "전체 년도" → "전체 연도". "수정하는중" → "수정하는 중".
   - 근무시간이 "8시 30분"으로 시각처럼 읽혔다 → "8시간 30분".
5. 남긴 결함(다음 카드 "인사 화면 결함"):
   - 근태 상태 필터를 골라도 조회 조건에 안 들어간다.
   - 교육 지정 모달이 경고만 띄우고 그대로 제출한다.
   - 프로그램 수정 모달이 고친 이름이 아니라 원래 이름이 비었는지 본다.
   - 교육 시간 입력 예시가 "8시간, 2일"인데 값은 `Number()` 라 NaN 이 된다.
   - 교육 카드에 온라인 여부(boolean)를 그대로 넣어 아무것도 안 보인다.
   - 교육 탭 id 가 근태 탭을 복사한 'attendance', 'leave'.
   - 공통 `useDropdown` 의 "전체"는 영어 화면에서도 한국어(공통 컴포넌트 i18n 때).
6. 한국어 문자열 1,272 → 971. 첫 로드: 인사 +3.1KB, 정적 렌더 유지.
7. 확인: tsc, lint 0, vitest 466, build, 인사 관련 e2e 4파일 58 통과 2 skip(전체는 CI), 리뷰 지적 없음. 구현은 erp-dev 에이전트, 문구와 "팀팀"은 메인 세션.
