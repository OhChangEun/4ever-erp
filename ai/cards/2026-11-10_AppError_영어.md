# AppError 오류 줄 영어

- 출처: i18n 10 결과 3
- 구현: Codex(gpt-6.1-sol, ultra), 리뷰: Claude(역할 교대)

## 결과

1. `src/lib/AppError.ts` 가 한국어 문구(`ERROR_MESSAGE_BY_KIND`, `errorMessageOf`, `requestIdLabelOf`)를 직접 만들어 영어 화면에도 한국어 오류 줄이 보였다. `src/lib` 는 언어를 모르고 `kind` 만 둔다. 화면은 `src/i18n/useErrorMessage.ts` 의 `useErrorMessage`, `useRequestIdLabel` 로 `errors` 메시지를 꺼낸다.
2. 호출부 약 40곳(TableStatusBox, StatSection, 각 도메인 모달과 탭의 토스트)을 훅으로 바꿨다. 한국어 문구 10개는 예전과 글자까지 같다.
3. 서버 본문 메시지는 화면에 붙이지 않는다(1차 구현이 붙였다가 리뷰 P1 로 되돌림. 예전에도 보이지 않았고, 서버 내부 문구가 사용자에게 보일 수 있다).
4. 테스트: 영어와 한국어 오류 줄, 요청 ID 라벨, 서버 메시지가 붙지 않음.
