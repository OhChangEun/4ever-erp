# 시각화 7: BOM 트리 원가 롤업과 비중 색, 접기

- 출처: 계획 17-1 "생산 BOM: 기존 D3 트리에 원가 롤업(하위 합계)과 수량 heat 색, 접기 상태 URL 보존", 17-2 규칙
- 우선순위: 2(단가 없는 자재를 0 원으로 숨기지 않는다), 1(합계는 화면이 아니라 계약의 단가에서 계산하고 같은 값을 표와 트리가 쓴다), 4(D3 가 DOM 을 직접 만지던 코드를 간트와 같은 방식으로)
- 브랜치: feat/시각화\_7\_BOM\_원가\_롤업
- 크기: 반나절

## 현상

BOM 상세의 트리는 이름과 수량만 보인다. 완제품 하나에 자재비가 얼마 드는지, 어느 자재가 원가를 많이 차지하는지 모른다. 트리는 D3 가 effect 안에서 DOM 을 직접 만들고(`D3TreeChart.tsx`), 색은 깊이별 고정 색(빨강, 파랑, 초록, 노랑)이라 디자인 토큰 밖이다. 하위가 많으면 접을 수 없다.

## 완료 기준

1. 계약 `BomLevelStructureNode` 에 `unitCost`(선택, 원/단위, null 가능). 자재(잎)에만 오고 상위는 화면이 계산한다. 목 BOM 을 3단(완제품, 조립품, 자재)으로 늘리고 한 자재는 단가를 비운다.
2. 원가 롤업: 노드 1단위 원가 = 하위마다 수량 × 하위 1단위 원가의 합. 완제품 1개에 대한 기여 = 경로의 수량 곱 × 1단위 원가. 비중 = 기여 / 완제품 원가.
3. 단가 없는 자재가 아래에 있으면 그 노드와 위 노드는 "이상"(아는 것만의 합)으로 표시하고, 자재 노드는 점선 테두리와 "단가 없음". 0 원으로 계산하지 않는다고 요약에 적는다.
4. 노드 색은 비중 4단계(blue-50, 100, 200, 300). 깊이별 고정 색을 없앤다.
5. 하위가 있는 노드는 눌러서 접고 편다(Enter, Space 도). `aria-expanded`. 접힌 노드에 "하위 N개 접힘".
6. 요약 문장(완제품 1개 자재 원가, 비중 큰 자재 3개, 단가 없는 자재 수)과 "표로 보기"(깊이 순서, 수준, 품목, 수량, 1단위 원가, 기여, 비중).
7. D3 는 `d3.tree` 로 좌표만 계산하고 React 가 SVG 를 그린다(간트와 같은 방식). 마우스 휠 확대는 빼고 스크롤로 본다.

## 결정 (AI 가 정함)

1. 색은 수량이 아니라 원가 비중. 수량은 단위가 달라(EA, kg) 서로 비교가 안 된다.
2. 접기 상태를 URL 에 두지 않는다. BOM 트리는 모달 안에 있고 모달 자체가 URL 에 없어 새로고침하면 모달이 닫힌다. 모달을 URL 로 여는 일이 생기면 그때 같이 옮긴다.
3. 휠 확대를 뺀다. 모달 안에서 휠이 확대에 잡히면 모달 스크롤이 막힌다. 접기와 가로, 세로 스크롤로 대신한다.
4. 원가는 자재비만. 공정 가공비는 라우팅에 금액이 없어 넣지 않는다.
