# 접근성 2: 모달 포커스 가두기, Esc, 포커스 복귀(Radix Dialog)

- 출처: 계획 10절과 결정 2(Dialog, Select, Popover 는 headless), 블록 6. 기존 계획의 "모달 focus trap 없음"
- 우선순위: 2(키보드 사용자가 모달 뒤 화면에서 길을 잃음), 4
- 브랜치: feat/접근성_2_모달
- 크기: 반나절

## 현상

1. 모달(`ModalContainer`)이 열려도 포커스가 모달 안으로 가지 않는다. Tab 을 누르면 뒤 화면으로 나간다.
2. Esc 로 닫히지 않고, 닫은 뒤 포커스가 연 버튼으로 돌아가지 않는다.
3. 모달 뒤 화면을 스크린리더가 그대로 읽는다(aria-hidden 없음).

## 완료 기준

1. 모달 틀을 Radix Dialog 위에 올린다. 포커스 가두기, Esc(맨 위 모달만), 닫은 뒤 연 버튼으로 복귀, 뒤 화면 aria-hidden.
2. 바깥(배경) 클릭으로는 닫지 않는다(지금 동작 유지, 입력 중인 폼 보호).
3. 테스트 5개(위 동작), 모달을 연 상태의 axe e2e.
4. 테스트, 빌드, e2e 통과. 첫 로드 JS 증가량을 적는다.

## 결정 (AI 가 정함)

1. 결정 2 대로 Radix(`@radix-ui/react-dialog` 1.3.1). 직접 짠 포커스 가두기(ConflictDialog 의 것)를 넓히는 것보다 겹친 모달, 스크롤 잠금, aria-hidden 을 검증된 코드에 맡긴다.

## 결과

1. 모달 틀을 Radix Dialog 로 옮겼다. 포커스 가두기, Esc(맨 위 모달만), 닫힌 뒤 연 요소로 포커스 복귀, 뒤 화면 aria-hidden. 배경 클릭으로는 닫지 않는다. 연 요소는 `addModal` 때 `document.activeElement` 로 기억한다(Dialog.Trigger 가 없어서).
2. 모달 단위 테스트 9개(처음 5개 + 리뷰 뒤 4개: 모달 안 드롭다운 클릭, 달력 Esc, 충돌 안내 Esc, 드롭다운 Esc 두 번).
3. 모달을 연 상태의 axe e2e 가 처음엔 실패했다. label(critical) 6, select-name(critical) 3, color-contrast(serious) 7. 모달 폼 13개의 label 69개가 입력과 이어져 있지 않았다. `useId` 로 id 와 htmlFor 를 이었다(수주 등록의 품목 줄은 index 를 붙임). 색 대비는 등장 페이드 중에 검사해서 생긴 것이라 e2e 가 끝이 있는 애니메이션이 끝난 뒤 검사한다.
4. 리뷰 P1: Radix 모달이 body 에 `pointer-events: none` 을 걸어 body 로 portal 되는 드롭다운 항목을 못 눌렀다. 공통 `PopoverPortal` 이 모달 안이면 모달 틀 안으로 붙인다. Dropdown, CalendarButton, DropdownInputModal, DropdownInputListModal 4개가 쓴다. e2e(교육 프로그램 추가의 카테고리 고르기)를 추가했고 옛 portal 로 돌리면 실패하는 것을 확인했다.
5. 리뷰 P2: 안쪽 층이 떠 있으면 모달은 Esc 를 넘긴다. Dropdown 3종에 `useCloseOnEscape` 를 붙였다. 드롭다운의 화살표 키 이동은 접근성 3 카드.
6. 첫 로드 JS(gzip): Radix 를 그냥 넣으면 모든 private 화면이 +12.7KB(dashboard 241.2 → 253.9). 모달 틀을 `next/dynamic` 으로 빼고 idle 때 미리 받게 해 dashboard 242.3, finance 242.9(+1.2), warehouse 226.9(-0.1), production 290.5(-0.3). main 은 같은 스크립트로 worktree 빌드해 쟀다.
7. 확인: lint 0 errors(경고 477 그대로), tsc, vitest 292, build, e2e 56 통과 2 skip.
8. 남은 것: 모달 틀이 처음 열릴 때 청크를 아직 못 받았으면(idle 전에 바로 누름) 오버레이만 잠깐 보인다. 청크 로드 실패 처리는 없다. 둘 다 verified=false 로 둔다.
