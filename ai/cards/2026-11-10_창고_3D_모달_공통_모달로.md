# 창고 3D 모달을 공통 모달로

- 출처: 시각화 8 결과 7번(발견한 결함)
- 우선순위: 2(키보드 사용자가 모달에 갇히거나 뒤 화면으로 빠지지 않는다), 4(모달은 ModalProvider 로만, CLAUDE.md "모달 열기")
- 브랜치: fix/창고\_3D\_모달\_공통\_모달로
- 크기: 1시간

## 현상

창고 목록의 "3D 보기"는 직접 만든 `fixed` 오버레이를 띄운다. Esc 로 닫히지 않고, 포커스가 모달 안에 갇히지 않으며, 닫은 뒤 포커스가 연 버튼으로 돌아오지 않는다. 제목도 없어 화면 낭독기가 dialog 이름을 못 읽는다.

## 완료 기준

1. `openModal(Warehouse3DModal, { title: '창고 3D 뷰 - 창고 이름', width: '900px', ... })`. 모달 내용은 3D 와 옆 칸만.
2. Esc 로 닫히고 포커스가 "3D 보기" 버튼으로 돌아온다(e2e).
3. 3D 안의 "재고 상세 열기"는 그 위에 겹쳐 열리고, Esc 는 위 모달만 닫는다(기존 공통 모달 동작).

## 결정 (AI 가 정함)

1. 너비는 900px. 공통 모달의 최대 너비 900px 은 사람이 정한 값이다(커밋 1f85061 "모달 최대 너비 900px로 고정"). 3D 를 위해 바꾸지 않는다.

## 결과

1. `Warehouse3DModal` 은 `ModalProps` 를 받는 내용 컴포넌트가 됐고, `WarehouseList` 의 3D 상태 3개(`show3DModal`, 고른 창고 id, 이름)를 지웠다.
2. e2e: 제목 있는 dialog, Esc 로 닫힘, 포커스 되돌림. 접근성 e2e 와 차트 e2e 24개 통과.
3. 첫 로드 JS: 창고 +1.3KB(시각화 8 과 같음). 리뷰 지적 없음.
