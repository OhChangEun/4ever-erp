## 완료 기준

1. 차트 짧은 금액 `compactWon`(재무 월별 차트 Y 축, 대시보드 자재 흐름 Sankey 라벨): 한국어는 예전과 글자 하나까지 같고, 영어 화면은 120M, 35M, 9K. 언어는 컴포넌트가 `useLocale()` 로 넘긴다. `src/app/utils` 에는 React 훅을 넣지 않는다.
2. 언어 인자 없는 `toLocaleString()` 과 `toLocaleString('ko-KR')`(number.ts 밖)을 `formatNumber` 로. 브라우저 언어가 de-DE 여도 자리 구분은 쉼표. ko, en 브라우저의 보이는 글자는 예전과 같다.
3. 견적 검토 모달의 재고 확인 시각이 브라우저 언어 대신 화면 언어를 따른다. 한국어 글자는 예전과 같다.
4. `formatCurrency` 는 두 언어 모두 ₩ 와 쉼표 그대로(결정 기록 금액과 숫자 언어별 형식 행). 날짜 유틸은 건드리지 않는다.

## 결과

1. `compactWon(n, locale)`: locale 이 `'en'` 이면 `Intl.NumberFormat('en-US', { notation: 'compact', maximumFractionDigits: 1 })`, 아니면 예전 한국어 분기. locale 은 필수 인자로 했다. 기본값을 두면 Recharts `tickFormatter={compactWon}` 이 두 번째 인자로 눈금 index 를 넘겨 언어 자리에 숫자가 들어간다. 그래서 `MonthlyChart` 는 `(v: number) => compactWon(v, locale)` 로 바꿨다.
2. `SupplyFlowChart`, `MonthlyChart` 가 `useLocale()` 로 언어를 넘긴다. 둘 다 이미 클라이언트 컴포넌트다.
3. `formatNumber` 로 바꾼 곳(14파일): 재고 목록 표, 안전재고 목록, 재고 발주 요청 모달, 품목 추가 모달 단가, 재고 추이 요약과 표, 재고 추이 차트 툴팁, 생산 주문 탭, 계획 주문 탭, MRP 발주 요청 모달 수량, 시뮬레이션 결과 모달, BOM 입력 폼 단가, 발주서 상세 수량, 창고 3D 합계 수량, 통계 카드(`src/lib/CreateStatCard.ts`). 값이 비면 예전엔 런타임 오류였고 이제 `-` 다(formatNumber 동작).
4. `QuoteReviewModal` 확인 시각은 `toLocaleTimeString(locale, { hour: '2-digit', minute: '2-digit' })`. 한국어는 `오후 03:05` 로 예전과 같고 영어는 `03:05 PM`.
5. 첫 로드 JS(gzip, KB). 고치기 전은 같은 트리를 stash 하고 `pnpm build` 뒤 `node scripts/measure-bundle.mjs --json`, 후는 같은 명령. 비교는 `node scripts/bundle-diff.mjs <전> <후>`.

## 별도 보고

1. 영업 차트의 짧은 금액(`src/app/(private)/sales/utils.ts` `toShortWon`)은 영어에서 `₩120M` 으로 ₩ 를 붙이고, `compactWon` 영어는 `120M` 이다. 두 함수가 따로 있다.
2. `QuoteReviewModal` 확인 시각은 렌더마다 `new Date()` 라 다시 그려질 때 바뀐다. 서버 응답의 `inventoryCheckTime` 은 쓰지 않는다.
3. 날짜가 브라우저 언어를 따르는 곳: `MrpPurchaseRequestModal.tsx:123` `toLocaleDateString()`, `SimulationResultModal.tsx:122` 은 영어 화면에도 `'ko-KR'` 고정.
4. `packages/ui/src/Sparkline.tsx:14` 와 `apps/portal/src/app/orders/page.tsx` 는 `toLocaleString('ko-KR')` 를 직접 쓴다. 패키지와 다른 앱이라 앱의 `formatNumber` 를 가져올 수 없어 두었다.
5. `QuoteReviewModal` 재고 확인 표의 필요 수량, 재고 수량은 자리 구분 없이 그대로 찍힌다(1200).
6. `SimulationResultModal` 수량 뒤 `EA` 는 서버 단위가 아니라 고정 글자다.
