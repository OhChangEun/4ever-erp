## 결정 질문 (게이트 1)

브리프가 정한 것: 위 고칠 것 1~5, 손대지 않는 것(별도 보고 1, 2, 3, 4, 10, 모달 안), 정적 검사와 primary e2e 를 둔다는 것.

AI 가 정한 것(`ai/decisions.md` "카드 남은 접근성과 디자인 (AI 결정)" 행):

1. MES 의 `scrollable-region-focusable` 은 브리프가 짚은 단계 가로 줄이 아니라 공통 표의 세로 스크롤 칸이었다(axe 대상 `.custom-scroll` = `Table.tsx:82`). 선택지 a 모든 표의 스크롤 칸에 `tabIndex` / b `Table` 에 선택 속성 `scrollLabel` 을 두고 행에 누를 것이 없는 MES 만 넘김 / c 스크롤이 없게 배치. 추천 b. a 는 버튼이 있는 표에도 Tab 정지가 하나 늘고, c 는 표 안 스크롤 규칙(`ARCHITECTURE.md` 6절)과 부딪친다. 이름은 새 메시지 `production.mes.tableLabel`("작업지시 목록", 빈 목록 문구와 같은 말).
2. 글자 크기 하한. 지침에 숫자가 없다. 앱 표 머리가 쓰는 가장 작은 단계 `text-xs`(12px)로. 회색은 `tokens.css` 주석이 흰 바탕 4.5:1 을 보장한 `gray-500`. 같은 파일의 다른 `text-gray-400` 글자(단위, 날짜, 모르는 상태)도 axe 가 같이 잡아 같이 바꿨다.
3. 카드 동작 모양. 브리프의 "텍스트 링크" 는 표 작업 열이 쓰는 `Button variant="ghost" size="sm"` 으로(같은 컴포넌트, 새 모양 없음). 창고 카드의 링크 셋은 그대로. "최대 2개, 넘으면 ⋯" 은 표 작업 열 규칙이고 ⋯ 메뉴 컴포넌트가 없어 새로 만들어야 한다.
4. 교육 프로그램 카드도 카드마다 primary 였다(브리프 목록 밖). 새 e2e 가 같은 위반으로 잡아 창고와 같은 방식으로 고쳤다.
5. 아이콘 대신 무엇을. 창고 카드 행은 등록 폼 라벨(`warehouse.form.type`, `location`, `manager`, `phone`)을 다시 쓴 `dl`. 교육 카드 행은 `hrm.programs.hours`, `mode` 와 새 메시지 `hrm.programs.capacity`("정원") 하나. 최근 이동과 알림 출처는 같은 뜻의 글자가 이미 있어 아이콘과 색 타일만 지웠다(보라, 남색도 같이 사라짐). 카드 목록은 `ul role="list"` + `li`(카드 하나를 테스트가 역할로 찾는다).
6. 정적 검사 모양. 지침 허용 세 곳은 `ICON_HOMES`, 나머지는 `ALLOWED`. 둘 다 파일, 개수, 이유가 정확히 맞아야 한다(기존 규칙과 같다). 브리프 목록 밖의 아이콘(빈 상태 그림, 쪽 이동 화살표, 토스트 등)은 고치지 않고 `ALLOWED` 에 "이 카드 범위 밖, 카드 별도 보고" 로 둔다.
7. primary 를 세는 법. 브랜드 블루(`bg-blue-500`) 채움 버튼, 비활성 포함(같은 남색으로 보인다. 앞 카드 프로필 검사와 같다). 지금 쪽 번호(`aria-current="page"`)는 위치 표시라 안 센다. 대화상자, 목록 상자, 메뉴 안은 뺀다.
