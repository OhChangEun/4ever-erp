# i18n 6: 재고와 재고 부족 화면

- 출처: i18n 2 결과 6
- 브랜치: feat/i18n\_6\_재고

## 결과

1. 재고 화면 문구 222 → 3, 재고 부족 화면 23 → 0. 재고 목록, 입고와 출고 관리 탭, 재고 이동 기록, 재고 추이 차트, 부족 알림, 모달 6개(추가, 상세, 이동, 구매 요청, 안전 재고, 출고 상세), 통계 카드. 남은 3개는 서버가 보내는 이동 유형 값 `입고`, `출고`, `이동`이라 `MOVEMENT_TYPE` 에 그대로 뒀다.
2. 메시지 묶음: `src/i18n/messages/inventory`, `src/i18n/messages/lowStock`. 창고 화면과 재고 부족 화면은 재고 모달을 같이 쓰므로 두 레이아웃이 `InventoryMessages` 를 같이 감싼다.
3. 같이 고친 문구 실수:
   - 구매 요청 모달의 "납품서 번호" → "발주서 번호".
   - "낙기일" 오타 → "납기일".
   - 재고 상세 모달 제목이 "재고 이동 기록"이었다 → "재고 상세".
   - 재고 부족 목록 제목 → "재고 부족 품목".
4. 남긴 것(별도 카드 후보):
   - 재고 분류와 창고 유형이 코드 그대로 보인다.
   - 목 데이터의 이동 유형이 `IN`/`OUT` 인데 아이콘은 `입고`/`출고` 를 기다린다.
5. 한국어 문자열 1,514 → 1,272. 첫 로드: 재고 +2.0KB, 재고 부족 +2.7KB, 창고 +4.1KB(재고 메시지를 같이 실어서). 예산 +5KB 안, 정적 렌더 유지.
6. 확인: tsc, lint 0, vitest 455, build, e2e 68 통과 2 skip. 전체 실행에서 5개가 시간 초과로 떨어졌고(dev 서버가 느려 전체 37분), 그 5개만 다시 돌리니 전부 통과. 리뷰 지적 없음. 구현은 erp-dev 에이전트, 문구 실수는 메인 세션.
