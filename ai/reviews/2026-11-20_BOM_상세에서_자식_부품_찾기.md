# BOM 상세의 계층 변환과 수량 0 리뷰

- 대상: 자식 조회 인덱스, 수량 정규화, 기존 모달 키보드 테스트 보강
- 리뷰어: Claude CLI 독립 diff 리뷰. 작성자가 Vitest 및 실제 Chrome 검증을 수행했다.

| 등급 | 확인한 내용                                                                 | 처리                                                                                                                  |
| ---- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| P2   | 고아 행이 섞이거나 루트가 두 개이면 첫 루트로 연결한 일부만 표시할 수 있다. | 후속 모달 카드에서 전체 입력과 집계된 품목 수를 대조하고, 일부만 연결될 때 기존 오류 화면을 표시하는 사례를 검증한다. |
| P3   | 키보드 Space의 스크롤 간섭과 포커스 유지 확인이 필요하다.                   | 실제 모달에서 Enter 후 Space로 복원하고 같은 노드에 포커스가 남는 e2e가 통과했다. 스크롤은 별도 휠 입력으로 확인했다. |
| P3   | 빈 자식 속성의 객체 모양을 지나치게 고정할 수 있다.                         | 테스트는 잎에서 하위 자재가 없다는 점, 형제 순서·수량·단가를 확인한다.                                                |
| 확인 | 명시적 수량 0이 트리에서 1로 집계되는 기존 사례                             | 테스트를 먼저 실패시킨 후 nullish 처리로 수정했다. 데모 상세 응답의 수량 한 칸만 바꿔 전후 표를 캡처했다.             |

수량 0 수정까지 포함한 2차 독립 리뷰에서 추가 P0·P1은 없었다. 리뷰어는 diff를 확인했고, 구현 측은 운영 빌드에서 트리의 0EA, 표의 기여 ₩0, Enter·Space 포커스 복원을 각각 확인했다.
