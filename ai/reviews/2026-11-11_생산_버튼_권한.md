# 2026-11-11 생산 버튼 권한 리뷰

- 대상: 작업 트리 diff. 구현 Claude(erp-dev), 리뷰 Claude(작성자를 가린 새 에이전트), 2차까지
- 결과: 1차 P2 1 / P3 2, 2차(추가로 숨긴 버튼) P3 2, 반영

| 차수 | 레벨 | 내용                                                                                                      | 처리                                                                            |
| ---- | ---- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 1    | P2   | 안전재고 화면 구매 요청 버튼이 IM, SD, PP 에게 보인다(stock-purchase-requisitions 는 MM 과 전체 관리자만) | 같은 상수로 숨김                                                                |
| 1    | P3   | 카드의 모달 위치가 틀림                                                                                   | `/low-stock` 으로                                                               |
| 1    | P3   | 버튼이 숨은 역할에게도 행 체크박스가 남는다                                                               | 남김(표 구조 변경 최소). 결정 행에 이유                                         |
| 1    | 권고 | 게이트웨이의 다른 권한 검사 확인                                                                          | 구매 요청 승인과 반려, 공급업체 등록(MM), 창고 추가와 재고 이동(IM) 버튼도 숨김 |
| 2    | P3   | 승인, 반려를 프록시 규칙에서 뺀 이유가 주석에 없다                                                        | 주석 추가                                                                       |
