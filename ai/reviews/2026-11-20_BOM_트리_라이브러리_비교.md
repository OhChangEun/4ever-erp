# BOM 초기 표시와 라이브러리 비교 리뷰

- 대상: 전체 원가와 표를 유지하면서 큰 트리의 처음 표시 범위를 정하고 조립품을 단계적으로 펼치는 변경
- 리뷰어: Claude CLI 독립 diff 리뷰 2회. Codex가 입력 사례, 테스트와 운영 빌드의 브라우저 결과를 대조했다.

| 등급                     | 지적                                                                        | 처리와 확인                                                                                                                                                                                                                                                                                    |
| ------------------------ | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P2                       | 상자의 상단 좌표만 기준으로 삼으면 완제품 원가가 화면 아래에 잘릴 수 있다.  | 상자 높이와 기존 배치 여백까지 480px 안에 들어오는지 두 곳에서 검사한다. 직속 자재 11개에서는 모두 표시하고, 12개에서는 루트부터 표시하는 경계 테스트를 추가했다.                                                                                                                              |
| P1 추정 → 재현 입력 구분 | 같은 부품이 여러 조립품에 들어가면 행 수 검사로 정상 원가가 거부될 수 있다. | 트리의 행 ID와 업무상 품목 코드를 구분한다. 같은 품목 코드·서로 다른 행 ID가 두 곳에 있는 입력은 2개 + 3개의 기여 500원을 집계했다. 동일한 행 ID로 다른 위치를 표현하면 기존 원가 Map의 결과가 모호하므로 오류를 표시한다. 업스트림의 행 ID 생성 규칙은 게이트웨이 사본만으로 확인되지 않았다. |
| P2 추정                  | 펼친 뒤 다른 노드로 포커스가 이동할 수 있다.                                | SVG의 key는 행 ID다. 직속 자재 30개를 펼친 브라우저에서 해당 노드가 화면 안에 있었고 포커스가 유지됐다. 스크롤 조정은 차트의 세로 스크롤에 한정했다.                                                                                                                                           |
| P3                       | 동일 BOM 재조회에서 구조 크기가 달라지면 기본 펼침 상태도 달라진다.         | 직접 열고 닫은 노드의 선택을 우선한다. 손대지 않은 노드는 새 데이터에 맞춰 초기 가시성을 계산한다. 단위 테스트에서 새 응답 객체에서도 사용자가 연 조립품이 열린 상태임을 확인했다.                                                                                                             |
| 기능 확인                | 고아 행이나 둘째 루트만 누락된 부분 원가가 보일 수 있었다.                  | 집계된 행 수와 전체 입력 행 수가 다르면 기존 오류 안내를 표시한다. 실제 브라우저 두 사례에서 오류 표시와 부분 총액 숨김을 확인했다.                                                                                                                                                            |
